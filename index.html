BUILT TO EXPERIMENT

Learn the feel. Then test it in your engine.

These are eight PD and spring variants running the same body-relative hand motion. The targets move with each player's body, so their world-space paths diverge during locomotion. This is an educational translational contact model, not a PhysX or Rapier benchmark. The PID URL is easy to remember; these modes have no integral term.
